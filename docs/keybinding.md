## 📝 How to Use

### Method 1: Keyboard Shortcut (⭐ Fastest)

```bash
# Universal Build (select environment)
Ctrl+Shift+B → Select "dev/stg/prod"

# Quick Build (no selection)
Ctrl+Shift+1 → Build APK Dev immediately
Ctrl+Shift+2 → Build APK Stg immediately
Ctrl+Shift+3 → Build APK Prod immediately
```

### Method 2: Command Palette

```bash
Ctrl+Shift+P → "Tasks: Run Task" → Select task
```

### Method 3: VSCode Menu

```bash
Terminal → Run Task... → Select task
```

## 🎯 Common Workflows

### 1. Development Workflow (Daily)

```bash
# Step 1: Start build runner watch
Ctrl+Shift+W  # Auto-generate code on save

# Step 2: Start debugging
F5            # Or use launch config

# Step 3: Make changes, save, hot reload automatic

# Step 4: When done
Shift+F5      # Stop debugging
```

### 2. Quick Test Build

```bash
# Build APK for quick testing
Ctrl+Shift+1  # Dev APK (fastest)

# Or staging
Ctrl+Shift+2  # Stg APK
```

### 3. Before Commit

```bash
# Step 1: Format code
Ctrl+Alt+F    # Dart Format

# Step 2: Analyze
Ctrl+Alt+A    # Flutter Analyze

# Step 3: Generate final code
Ctrl+Shift+R  # Build Runner (one-time)

# Step 4: Test build
Ctrl+Shift+1  # Build APK Dev
```

### 4. Production Release

```bash
# Step 1: Clean project
Ctrl+Shift+C  # Clean & Get

# Step 2: Generate code
Ctrl+Shift+R  # Build Runner

# Step 3: Generate i18n
Ctrl+Alt+L    # Generate l10n

# Step 4: Build AAB for Google Play
Ctrl+Alt+3    # Build AAB Prod (with obfuscation)

# Or build APK for testing
Ctrl+Shift+3  # Build APK Prod
```

### 5. iOS Release

```bash
# Step 1: Clean
Ctrl+Shift+C

# Step 2: Generate code
Ctrl+Shift+R

# Step 3: Build IPA
Ctrl+Shift+P → Select "prod"

# Or build iOS app
Ctrl+Shift+I → Select "prod"
```

## 🔥 Pro Tips

### 1. Universal vs Quick Builds

**Universal Builds** (với selector):
- `Ctrl+Shift+B` - APK Universal
- `Ctrl+Shift+A` - AAB Universal
- `Ctrl+Shift+I` - iOS Universal
- `Ctrl+Shift+P` - IPA Universal

**Quick Builds** (no selector):
- `Ctrl+Shift+1/2/3` - APK Dev/Stg/Prod
- `Ctrl+Alt+1/2/3` - AAB Dev/Stg/Prod

### 2. Build Output Locations

```bash
# APK
build/app/outputs/flutter-apk/app-{flavor}-release.apk

# AAB
build/app/outputs/bundle/{flavor}Release/app-{flavor}-release.aab

# iOS
build/ios/iphoneos/Runner.app

# IPA
build/ios/ipa/*.ipa
```

### 3. Parallel Tasks

Bạn có thể chạy nhiều tasks cùng lúc:

```bash
Terminal 1: Ctrl+Shift+W  # Build Runner Watch
Terminal 2: F5             # Debug Run
Terminal 3: Ctrl+Shift+1  # Build APK in background
```

### 4. Custom Shortcuts

Thêm shortcuts riêng trong `.vscode/keybindings.json`:

```json
{
  "key": "ctrl+alt+x",
  "command": "workbench.action.tasks.runTask",
  "args": "Your Custom Task"
}
```

## 🐛 Troubleshooting

### Shortcut not working?

1. **Reload VSCode**
   ```bash
   Ctrl+Shift+P → "Developer: Reload Window"
   ```

2. **Check keybindings.json exists**
   ```bash
   .vscode/keybindings.json
   ```

3. **Check tasks.json has correct labels**
   ```bash
   .vscode/tasks.json
   ```

### Conflict with other extensions?

Check existing shortcuts:
```bash
Ctrl+K Ctrl+S → Open Keyboard Shortcuts
Search for conflicting shortcuts
```

### Task not found?

Make sure task label in `keybindings.json` matches exactly with `tasks.json`:
```json
// keybindings.json
"args": "🚀 Build APK (Universal)"

// tasks.json
"label": "🚀 Build APK (Universal)"
```
