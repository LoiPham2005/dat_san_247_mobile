// THAY BẰNG implementation mới:
```dart
Future<void> _logAdEvent(AdPlacement placement, String event, {Map<String, dynamic>? params}) async {
  Logger.info('📊 Ad event: ${placement.key} - $event', tag: 'ADS');

  // Track với AdAnalyticsTracker
  switch (event) {
    case 'load_start':
      _analyticsTracker.trackAdLoadStart(placement);
      break;

    case 'load_success':
      await _analyticsTracker.trackAdLoadSuccess(
        placement,
        additionalParams: params,
      );
      break;

    case 'load_failure':
      await _analyticsTracker.trackAdLoadFailure(
        placement,
        errorCode: params?['error_code'] ?? 'unknown',
        errorMessage: params?['error_message'],
        retryCount: params?['retry_count'],
        additionalParams: params,
      );
      break;

    case 'impression':
      await _analyticsTracker.trackAdImpression(
        placement,
        estimatedRevenue: params?['revenue'],
        currency: params?['currency'] ?? 'USD',
        additionalParams: params,
      );
      break;

    case 'click':
      await _analyticsTracker.trackAdClick(
        placement,
        additionalParams: params,
      );
      break;

    case 'dismissed':
      await _analyticsTracker.trackAdDismissed(
        placement,
        viewDurationSeconds: params?['view_duration'],
        additionalParams: params,
      );
      break;

    case 'show_failed':
      await _analyticsTracker.trackAdShowFailure(
        placement,
        errorCode: params?['error_code'] ?? 'unknown',
        errorMessage: params?['error_message'],
        additionalParams: params,
      );
      break;

    case 'reward_earned':
      await _analyticsTracker.trackRewardEarned(
        placement,
        rewardType: params?['reward_type'] ?? 'coins',
        rewardAmount: params?['reward_amount'] ?? 0,
        additionalParams: params,
      );
      break;
  }
}
```

## BƯỚC 7: Kiểm tra Firebase Console

1. **Realtime View:**
   - Mở Firebase Console → Analytics → DebugView
   - Run app với `--dart-define=FIREBASE_DEBUG=true`
   - Xem các events realtime khi test ads

2. **Events Dashboard:**
   - Firebase Console → Analytics → Events
   - Xem các custom events như:
     - `ad_load_success`
     - `ad_load_failure`
     - `ad_impression`
     - `ad_click`
     - `ad_dismissed`
     - `ad_show_failed`
     - `ad_reward_earned`

3. **Conversion Events:**
   - Mark `ad_click` as conversion event
   - Mark `ad_reward_earned` as conversion event
   - Dùng để optimize ad targeting
